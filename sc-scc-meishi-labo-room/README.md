# SC.SCC名刺Labo room

スマホだけで、QRコード入りの名刺をつくって、カードケースにしまって、印刷までできる名刺ツールです。
`index.html` の1ファイルだけで動きます。ビルドも、サーバーも要りません。

## 開き方
- `index.html` をブラウザで開きます。
- ほかの人に渡すときは、GitHub Pages で公開すると、URLを送るだけで使えます。
  （リポジトリの Settings → Pages で、このブランチとフォルダを選びます）

## できること
- **名刺をつくる:** 10色のデザイン、3つのレイアウト（キラキラ高級／キラキラ高級協会スタイル／すっきり協会スタイル）、書体3つ＋ゴシック。
- **QRコード:** 裏面に必ず入ります。長いリンクのときは、読み取りにくくなる注意が出ます。
- **写真・ロゴ:** 表面に丸い写真を入れられます（写真なしも選べます）。協会スタイルは、ロゴ画像を選んでから保存します。
- **肩書き:** 候補をいくつでも足せます。自分で打つときは `/` で区切ります。
- **カードケース:** つくった名刺と、もらった名刺（写真・手入力）をしまえます。名前や会社で探せます。
- **印刷:** 名刺用紙（A4・10面・91×55mm）のPDFと、印刷所むけPDF（91×55mm・表裏）。
- **使い方:** アプリの中の「使い方」に、手順があります。

## 使うときの注意
- **ロゴ:** ロゴの画像は、このツールには入っていません。使う人が、自分の画像を、アプリの「ロゴ画像」から1回選びます（選ぶと、その端末に残ります）。ロゴの使用許可は、使う人が確認してください。
- **データの保存場所:** つくった名刺は、使っている人のブラウザの中（localStorage）だけに保存されます。ブラウザのデータを消すと、見えなくなります。大切な名刺は、画像でも保存してください。
- **オンラインが必要:** QRコード（qrcode-generator 1.4.4）、PDF（jsPDF 2.5.1）、フォント（Google Fonts）を、インターネットから読みこみます。
- **見本の文字:** はじめに入っている名前とリンクは見本です。QRのリンクが見本のままだと、保存・印刷できません。
- **自動読み取り:** もらった名刺の「写真から情報を読み取る」は、AI（Claude）の画面で開いたときだけ使えます。GitHub Pages などで開いたときは、写真を見ながら手で入力します。

## 印刷のコツ
倍率は「100％（実際のサイズ）」にして、「ページに合わせる」はオフにします。先に1枚だけ試し刷りをして、スマホのカメラでQRが読めるか確かめてください。
